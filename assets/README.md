# Order brand assets

The canonical Order mark uses an **aperture** metaphor: a blurred or unresolved idea is brought into focus and carried through to a verified result.

## Canonical files

- `order-symbol.svg` — full-colour symbol.
- `order-symbol-mono-dark.svg` — one-colour dark symbol.
- `order-symbol-mono-light.svg` — one-colour light symbol.
- `order-logo-light.svg` — horizontal logo for light surfaces.
- `order-logo-dark.svg` — horizontal logo on the canonical dark plate.
- `order-logo-plate-dark.svg` — README/hero lockup with the approved message hierarchy.

## Meaning

The aperture is a metaphor, not a literal camera product reference. It represents **bringing an idea into focus**: Order resolves what needs to happen, carries the work through the software factory, and returns a verified result.

## Primary copy

**Ideas in. Results out.**

**From idea to verified result.**

## Colour

- Ink: `#0f172a`
- Dark surface: `#111a29`
- Order blue: `#1e3a8a`
- Bright blue: `#2563eb`
- Light accent: `#60a5fa`
- White: `#ffffff`

The mark must remain legible in monochrome. Do not add checkmarks, arrows, workflow nodes, shields, or literal camera details to the symbol.
