# Order brand assets

The canonical Order mark is the approved **six-blade aperture** symbol.

It is a metaphor for bringing an unresolved idea into focus: Order carries software work from an idea through definition, implementation, testing, review, bounded remediation, and independent verification to a verified result.

## Canonical assets

- `order-symbol.svg` — canonical full-colour aperture symbol.
- `order-icon.svg` — canonical icon alias; identical geometry to `order-symbol.svg`.
- `order-symbol-mono-dark.svg` — monochrome dark symbol.
- `order-symbol-mono-light.svg` — monochrome light symbol.
- `order-logo.svg` — transparent horizontal symbol + wordmark.
- `order-logo-light.svg` — horizontal logo on a fixed light background.
- `order-logo-dark.svg` — horizontal logo on a fixed dark background.
- `order-logo-plate-dark.svg` — fixed-background README brand plate.

## Geometry authority

All variants use the same six aperture-blade silhouette traced from the approved visual concept selected during the branding session.

Do not redraw the aperture from memory, substitute a generic camera-aperture icon, add or remove blades, or create an alternate geometric construction for a specific surface.

## Primary copy

**Ideas in. Results out.**

**From idea to verified result.**

The messaging is rendered as README/product copy, not embedded into the canonical logo plate.

## Colour

- Ink: `#0f172a`
- Dark surface: `#111a29`
- Aperture blues: `#06398c`, `#0557d5`, `#0647b0`, `#0667e4`, `#073889`, `#0555d1`
- White: `#ffffff`

## Usage constraints

The aperture is a metaphor, not a literal camera product reference.

Do not add:

- checkmarks;
- workflow nodes;
- shields;
- factory illustrations;
- robot/AI sparkle motifs;
- arrows as the primary mark;
- camera bodies, lenses, or other literal photographic details.

For GitHub README use, prefer `order-logo-plate-dark.svg` because its fixed background renders consistently in both GitHub light and dark modes.
